# 🧱 Basic Multi-Page HTML Website

This project is part of the [roadmap.sh Basic HTML Website Challenge](https://roadmap.sh/projects/basic-html-website).

It’s a simple **multi-page website** created using **only HTML**, without any CSS or JavaScript.

---

## 📂 Pages Included
- `index.html` — Homepage  
- `about.html` — About Me  
- `project.html` — My Projects  
- `contact.html` — Contact Info  

---

## 🧠 Features
- Fully navigable website (all internal links work)
- SEO meta tags in every page
- Semantic HTML layout using `<nav>`, `<div>`, and `<footer>`
